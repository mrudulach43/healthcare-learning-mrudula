## C-CDA (Consolidated Clinical Document Architecture)

C-CDA is an HL7 standard used to exchange structured clinical 
documents between healthcare systems.

## Key Characteristics

- Document-centric approach.
- Uses XML format.
- Supports the exchange of complete clinical documents.
- Widely supported by Electronic Health Record (EHR) systems.

## Common Use Cases

- Patient medical summaries.
- Hospital discharge summaries.
- Continuity of care documents.
- Clinical progress notes.
- Care plans.

## Limitation

Retrieving a specific piece of patient information may require 
processing a large clinical document.

## FHIR (Fast Healthcare Interoperability Resources)

FHIR is an HL7 standard designed to simplify healthcare data 
exchange using modern web technologies and APIs.

## Key Characteristics

- Resource-based and modular approach.
- Supports JSON and XML formats.
- Commonly uses RESTful APIs.
- Supports targeted and real-time data exchange.

## Common Use Cases

- Mobile healthcare applications.
- Patient portals.
- Telehealth applications.
- Retrieving medications and allergies.
- Accessing laboratory results.
